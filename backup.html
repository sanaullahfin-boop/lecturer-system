Download Complete Backup

Exports every collection — students, courses, attendance, course plans, assignments/quizzes/tasks/presentations/exams and marks, gradebook adjustments, announcements, file/ebook links and your settings — into one file. Keep it somewhere safe (Google Drive, USB). It contains student passwords — keep it private.

Restore from Backup

Restoring merges the backup into your current data — records with the same ID are overwritten with the backup's version; nothing else is deleted. Accepts a .json or .xlsx backup from the buttons above.


Blank Excel Template

Headers only, one tab per collection — useful to see the exact layout.

Danger Zone — Reset All Data

Permanently deletes every record in every collection (your settings and admin login are kept). This cannot be undone — download a backup first. Student login accounts in Firebase Authentication are not removed (browser-only limitation); they simply become unused.
