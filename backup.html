Download Complete Backup

Exports every collection (students, courses, attendance, assignments, presentations, quizzes, tasks, exams, marks, gradebook adjustments, announcements, and course content/ebook metadata) into one file. Keep it somewhere safe — Google Drive, a USB drive, wherever you'd keep an important document.

Note: this backs up your data records, not the actual uploaded files themselves (those stay in Firebase Storage) — but the download links to them are included, so nothing is lost as long as Storage isn't separately cleared.

The Excel version opens directly in Excel/Google Sheets — one tab per collection — so you can browse or edit your data by hand if you ever need to. The JSON version is the more exact, recommended format for restoring; use Excel mainly for reading or lightly editing.

Restore from Backup

Restoring merges the backup into your current data — records with the same ID (e.g. the same roll number or course code) get overwritten with the backup's version; everything else is left alone. This does not delete records that exist now but aren't in the backup. Use this to recover after a mistake, or to move data between two Firebase projects. Accepts either a .json backup or an .xlsx backup (from the buttons above).


Blank Excel Template

If you're starting fresh and want to see the exact column layout before you have any real data to back up, download this empty version — one tab per collection, headers only, no rows.

Danger Zone — Reset All Data

Permanently deletes every record in every collection — students, courses, attendance, assignments/presentations/quizzes/tasks/exams and their marks, gradebook adjustments, announcements, and course content/ebook links. This cannot be undone — download a backup first if there's any chance you'll want this data later.

Your own admin login is never affected. Note: student login accounts also aren't deleted by this (a browser-only limitation — see the README) — they just become unused since their linked student records are gone.

Download a backup first before using this, unless you're certain.
