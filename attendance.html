Monthly Excel Upload

Download a sheet for a course and month (one column per class day — taken from your Course Plan if you have one, otherwise every day), fill each cell with one of your codes (P, A, L, Lt, E — see the Legend sheet), and upload it back. Blank cells are ignored, so you can upload part of a month and finish later. Existing marks are pre-filled in the template.

Students request leave from My Attendance in their app. When you Approve, any Absent marks already saved in those dates become Leave, and on the marking screen those students are set to Leave for you. Undo only changes the request — marks already changed stay as they are.

Live Check-in

Show a QR code and a 6-digit code on the board or projector. Students scan the QR with their phone camera (it opens the app with the code filled in), or open the app → Dashboard → Class Check-in and type the code. The code expires quickly, so only students in the room can use it.
